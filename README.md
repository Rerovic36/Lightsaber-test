
Esta es una apliacion interactiva de un sable de luz de Star Wars que realice hace un año como ejercicio para ir aprendiendo CSS

### `npm start`

Ejecuta la aplicacion en modo desarrollo.\
Abre [http://localhost:3000](http://localhost:3000) para visualizarlo en tu navegador.


### `npm run build`

Se utiliza para crear una version y ponerla en produccion
